# Epidemic Parameter Estimation

Estimate infection rate \(p\) (beta) and recovery rate \(q\) (gamma) from discrete SIR trajectories on static networks.
**Models**
- XGBoost (macroscopic features)
- 1D-CNN (temporal convolution on macroscopic features)
- GTA: GIN + Transformer over node states
Optional late fusion of an MLE estimate of \(q\).
Generate_networks are generated by Four_Generate_networks.py
real_networks are pre_processed by preprocess_real_network.py
Data is generated by Data_generate_sir_trajectories.py

## Data layout
Each file contains:
```python
{
  "trajectories": [ ((p, q), history_matrix), ... ],
  "node_mapping": { original_id: index, ... }
}
```
`history_matrix` has shape `(T+1, N)` with states `0=S`, `1=I`, `2=R`.

### NETWORK_ROOT (edge lists)
- `{net_name}.csv` or `{net_name}(N=...,K=...).csv`
- Columns: `source` / `target` (or `Source` / `Target`)

## Main experiments

Run all commands from the **repository root**.

```bash
# Plain models
python -m src.train_cnn
python -m src.eval_cnn
python -m src.train_xgb
python -m src.eval_xgb
python -m src.train_gta
python -m src.eval_gta

# Late-fusion MLE of q
python -m src.train_cnn_mle
python -m src.eval_cnn_mle
python -m src.train_xgb_mle
python -m src.eval_xgb_mle
python -m src.train_gta_mle
python -m src.eval_gta_mle
```

Edit paths, network names, and task lists in each script’s main block.

### Data split

Every block of 50 trajectories:

| Split | Indices |
|-------|---------|
| Train | 0–39 |
| Validation | 40–44 |
| Test | 45–49 |

### Task axes

- Vary `n_steps` (number of observation times)
- Vary `gap` (interval between observations)
- Optional synthetic grids over `N` and mean degree `K`

For a fixed ~30-day window joint sweep of `(n_steps, gap)`, reuse the same trainers and only change the task list (no separate model files).

## Robustness experiments

Same model classes as the main pipeline; features or observation masks change.

### Missing edges

Progressively drop edges. Macro features remain 7-D; GTA uses `node_in_dim=3`.

```bash
python -m src.robustness_missing_edges_train
python -m src.eval_robustness_missing_edges
```
### Unobserved nodes
Progressively hide node states (unknown class `U`). CNN/XGB use 8 channels; GTA uses `node_in_dim=4`.

```bash
python -m src.robustness_node_missing_train
python -m src.eval_robustness_node_missing
```
### Only-I observation + time window

Only infected nodes are observed. CNN/XGB use 4-D features; GTA uses `node_in_dim=2`. Sweep `n_steps`.

```bash
python -m src.robustness_only_i_train
python -m src.eval_robustness_only_i
```
### Pure MLE baseline for q
```bash
python -m src.mle_q_test
```
## Models (`src/models.py`)

| Class | Description |
|-------|-------------|
| `EpidemicCNN` | 1D-CNN on macroscopic series (`input_channels` configurable) |
| `EpidemicCNN_MLE` | CNN + late-fusion MLE \(q\) |
| `GTA` | GIN + Transformer dual readout (`node_in_dim` configurable) |
| `GTA_MLE` | GTA predicting \(p\) with fused MLE \(q\) |
| `MSLELoss` / `MSLELossSingle` | Training losses |
| `estimate_q_mle` | Discrete-time MLE for recovery rate |
| `get_mape` | MAPE metric |
| `set_seed` | Reproducibility (default seed 520) |
